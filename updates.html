Cenário · Central de Novidades

Este cenário prototipa uma solução simples para clientes que não sabem o que mudou no sistema: botão flutuante com drawer lateral e detalhamento sem sair da tela.

Como testar este cenário

  1. Clique em Novidades no canto inferior direito.
  2. Veja a lista das últimas novidades.
  3. Clique em uma novidade para abrir o detalhe no próprio drawer.
  4. Use Voltar para novidades para retornar à lista.
